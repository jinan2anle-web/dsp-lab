# D3 处理思路

## 文字流程图

```
[采集] 100 条 wav（"0"~"9" 各 10 条）
   ▼
[解析 read_wav] → x∈[-32768,32767]、fs=16000、单声道、16 bit（四元组，不归一化）
   ▼
[预处理] remove_dc → enframe(400,160,hamming) → 帧矩阵 [n,400]
   ▼
[三参数] 短时能量 E_n / 平均幅度 M_n / 归一化过零率 Z_n（三条逐帧曲线）
   ▼
[端点检测] T2 初判 N3/N4 → T1 搜索 N2/N5 → T3 定位 N1/N6 → seg
   ▼
[特征] time_domain_feature(normalize=True) → [T,3] = [lnE, lnM, Z]
   ├──────────────────────┐
   ▼                      ▼
[DTW 最近邻]            [16 维聚合] → KNN / SVM（训练集五折选参）
   └──────────┬───────────┘
              ▼
[评估] 50 条测试集 → 准确率 / macro-F1 / 混淆矩阵 / 逐条预测 / 预测耗时
```

## 每个模块一句话判据

| 模块 | 判据 |
|---|---|
| 采集 | 100 条全部 16 000 Hz、单声道、16 bit、24 000 点、削波 0；不满足即退回重录。 |
| 解析 | 返回四元组且不归一化；子块长度为奇数时按 `csize & 1` 补字节。 |
| 预处理 | `n_frames = 1 + floor((len(x) − 400)/160)`；特征窗恒为 hamming。 |
| 三参数 | E 与 M 全帧求和（不加均值），Z 归一到 [0,1]；量纲差异交给取对数与逐序列归一化。 |
| 端点检测 | T2 判有无语音，T1 定边界扩张，T3 定清音头尾；无语音返回 `None` 而非空 dict。 |
| 特征 | 归一化在段内逐维做，形状可比、长度不可比 → 必须用 DTW。 |
| 分类器 | 标准化与选参封在训练集五折内；DTW 的 `band = round(0.35 × max(n,m))`。 |
| 评估 | 固定 01–05 训练 / 06–10 测试，测试集只估一次；必报 macro-F1 与逐条预测。 |

## 三条口径决定

1. 端点后与整段两条都跑：整段 DTW 0.76 高于端点 DTW 0.54，说明裁剪在丢信息，这条差异本身就是结论，不做二选一。
2. 只对特征序列归一化，不对波形归一化——后者会抹掉音量，而音量正是短时能量要表达的。
3. 窗型比较传 `normalize=False`（要看绝对能量差异），分类主流程传 `True`；两处不同是故意的，须在产物里写明。
