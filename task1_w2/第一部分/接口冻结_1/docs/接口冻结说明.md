## 2. 数据契约（A 的交付义务）

### 2.1 文件命名与目录

- 命名：`{数字}_{序号:02d}.wav`，例 `0_01.wav`、`9_10.wav`
  - 数字：`0`~`9`，每类 10 组
  - 序号：`01`~`10`，两位数字
- 目录：**按说话人建文件夹**，例 `A/A/*.wav`；说话人标识由文件夹承担，不写进文件名
- 说话人 A 现状：100 个文件，符合上述全部规则

### 2.2 音频格式（硬约束）

| 项 | 取值 | 实测（A 的 100 个文件） |
|---|---|---|
| 采样率 | 16000 Hz | 100/100 一致 |
| 通道数 | 1（单声道） | 100/100 一致 |
| 量化位深 | 16 bit PCM | 100/100 一致 |
| 时长 | 约 1.5 s（24000 采样点） | 全部 24000 点，标准差 0 |
| 削波 | 不允许 | 0 个削波样点 |
| 直流偏置 | 尽量小 | 最大 2.6（满量程 32768） |

### 2.3 `read_wav(filepath)` -> `(wave_data, sample_rate, num_channels, bits_per_sample)`

本口径 **以 A 已提交的 `wav_parse/wav_parse.py` 为准**（口头讨论中曾拟定为 `(x, fs, info)`，现按实际代码冻结为四元组）。

| 返回位 | 类型 | 说明 |
|---|---|---|
| `wave_data` | `numpy.ndarray`，一维 `float64` | 16 bit PCM **原始量化值**，范围约 `[-32768, 32767]`，**不做归一化** |
| `sample_rate` | `int` | 本实验恒为 `16000` |
| `num_channels` | `int` | 本实验恒为 `1`；立体声输入按左声道输出为单声道 |
| `bits_per_sample` | `int` | 本实验恒为 `16` |

约定：RIFF 子块长度为奇数时补 1 个填充字节；缺少 `fmt`/`data` 子块抛 `ValueError`；非 16/8 bit PCM 抛 `ValueError`。

> 遗留问题（**第 2 周修复项**）：A 提交的 `wav_parse.py` 中 while 循环用 `f.read(sub_size)` 读取非 data 子块，遇奇数长度块（LIST/fact）会错位。公共模块 `speech_time_domain.read_wav` 已修正（`pos += 8 + csize + (csize & 1)`）。本实验录音无 LIST 块，尚未暴露，但接口冻结要求 A 同步修复。

## 3. 函数签名（冻结）

```
# ---- 预处理 ----
remove_dc(x)                          -> x - mean(x)            # 一维 float64
pre_emphasis(x, a=0.97)               -> 一维 float64（y[0]=x[0]）
enframe(x, frame_len, hop, win='hamming') -> (frames, w)
        frames  [n_frames, frame_len] float64，已乘窗
        w       [frame_len] 窗序列
        n_frames = 1 + floor((len(x) - frame_len) / hop)；len(x) < frame_len 时补零
        win ∈ {'rect', 'hamming', 'hanning'}，其它取值抛 ValueError

# ---- 短时特征（输入 frames，输出 [n_frames]）----
short_time_energy(frames)             -> E_n = Σ_{m} x_n²(m)
short_time_amplitude(frames)          -> M_n = Σ_{m} |x_n(m)|
short_time_zcr(frames)                -> Z_n = ½·Σ|sgn[x_n(m)] − sgn[x_n(m−1)]|
short_time_zcr_rate(frames)           -> Z_n / frame_len，取值 [0, 1]

# ---- 端点检测 ----
endpoint_detect(x, fs, frame_ms=25.0, hop_ms=10.0, win='hamming',
                is_ratio=0.4, noise_ratio=0.3, zcr_ratio=5.0,
                min_len_ms=100.0)
    -> dict 或 None

# ---- 识别 ----
time_domain_feature(x, fs, frame_ms=25.0, hop_ms=10.0, win='hamming',
                    normalize=True)   -> [T, 3] float64
dtw_distance(a, b, band=None)         -> 标量（已按路径长度 n+m 归一化）
DTWClassifier(band_ratio=0.35).fit(X, y) / .predict(X)
extract_file(path, **kw)              -> (feature, det, fs, info)
```

### 3.1 `endpoint_detect` 返回字段（必须齐全）

| 字段 | 含义 |
|---|---|
| `frames, E, M, Z` | 逐帧矩阵与三条短时特征序列 |
| `T1, T2, T3` | 低门限、高门限、过零率门限 |
| `N1 … N6` | 六个端点帧号（满足 `N1 ≤ N2 ≤ N3 ≤ N4 ≤ N5 ≤ N6`） |
| `start, end` | 语音段起止时间（秒） |
| `seg` | 语音段波形（一维） |

**异常语义**：无语音（纯静音/能量包络从未超过 `T2`）时返回 `None`，**不抛异常、不返回空 dict**；调用方负责跳过该样本。

**门限定义**：
- `T2 = max(E_noise × 10, max(E) × is_ratio)`（高门限，一次初判 N3/N4）
- `T1 = max(T2 × noise_ratio, E_noise × 8)`（低门限，搜索 N2/N5）
- `T3 = max(Z_noise × zcr_ratio, 1e-6)`（过零率门限，定位 N1/N6）
- `E_noise` / `Z_noise` 取前 10% 帧（至少 5 帧）的均值

### 3.2 `time_domain_feature` 与归一化口径

三维 = `[ln E_n, ln M_n, Z_n]`；`normalize=True` 时**在本段序列内**逐维零均值单位方差归一化（逐序列归一化）。

冻结判据：归一化后每一维满足 `|mean| < 1e-6` 且 `|std − 1| < 1e-6`。

> 口径说明：曾比较"全局归一化"与"语音段内相对能量"两种方案，均劣于逐序列归一化，故冻结为逐序列归一化。

### 3.3 `dtw_distance` 归一化口径

`return D(n, m) / (n + m)`，保证不同时长样本可比。冻结判据：`d(a,a) = 0`、`d(a,b) = d(b,a) ≥ 0`；`band` 为 Sakoe-Chiba 半宽（`DTWClassifier` 取 `band_ratio=0.35`）。
