# 实验一第三周第一部分交接说明

## 1. 本部分完成内容

本部分在第二周实验一基准流程上，补充完成了预处理消融、时域特征消融、DTW参数调节和重复划分稳健性实验。

实验统一使用现有100条数字语音录音，数字0—9每类10条。录音格式为16 kHz、单声道、16 bit PCM。基础参数为25 ms帧长、10 ms帧移和Hamming窗。

本次没有继续增加分类器，而是重点分析现有处理步骤、特征和参数是否真正有效。

## 2. 实验设计

### 2.1 预处理消融

使用逻辑回归作为统一分类器，比较以下四种输入：

1. 原始整段录音；
2. 去直流后的整段录音；
3. 去直流并完成端点检测后的语音段；
4. 去直流、端点检测并进行预加重后的语音段。

逻辑回归的参数C只使用训练集五折交叉验证选择，不使用测试集调参。

### 2.2 时域特征消融

比较以下五组特征：

1. 短时能量；
2. 短时幅度和；
3. 短时过零率ZCR；
4. 能量与幅度组合；
5. 能量、幅度和ZCR三类特征组合。

每组特征均保留语音段时长。单类特征组为5个统计量加时长，共6维；能量与幅度组为11维；三类特征组为16维。

### 2.3 DTW参数调节

比较DTW约束带比例：

`0.10、0.20、0.35、0.50、1.00`

参数选择以训练集留一验证结果为依据。如果多个参数结果相同，选择计算量较小的约束带。固定测试集只用于最后的描述性复核。

### 2.4 稳健性实验

除固定的每类01—05训练、06—10测试外，另外进行了10次分层随机50/50划分，以观察单次划分结果是否稳定。

随机种子固定为42。

## 3. 主要实验结果

### 3.1 预处理结果

| 预处理条件 | 测试准确率 | Macro-F1 |
|---|---:|---:|
| 原始整段 | 0.60 | 0.551 |
| 去直流整段 | 0.60 | 0.551 |
| 去直流＋端点检测 | **0.64** | **0.638** |
| 去直流＋端点检测＋预加重 | 0.58 | 0.551 |

结论：去直流本身没有改变当前分类结果；端点检测使准确率从60%提高到64%；增加预加重后准确率下降，因此实验一的时域统计特征不采用预加重。

### 3.2 特征消融结果

| 特征组合 | 测试准确率 | Macro-F1 |
|---|---:|---:|
| 短时能量＋时长 | 0.32 | 0.312 |
| 短时幅度和＋时长 | 0.34 | 0.317 |
| ZCR＋时长 | 0.54 | 0.511 |
| 能量＋幅度＋时长 | 0.50 | 0.509 |
| 能量＋幅度＋ZCR＋时长 | **0.64** | **0.638** |

结论：ZCR是三类单项特征中效果最好的特征；三类特征联合效果最好，说明能量、幅度和ZCR之间存在互补信息。

### 3.3 DTW调参结果

| 约束带比例 | 训练集留一准确率 | 固定测试准确率 | 预测耗时 |
|---:|---:|---:|---:|
| 0.10 | 0.56 | 0.70 | 约5.7 s |
| 0.20 | 0.64 | 0.74 | 约10.1 s |
| 0.35 | **0.68** | **0.76** | 约15.7 s |
| 0.50 | 0.68 | 0.76 | 约20.4 s |
| 1.00 | 0.68 | 0.76 | 约26.7 s |

结论：约束带达到0.35后准确率不再提高，但耗时继续增加，因此最终选择`band_ratio=0.35`。

### 3.4 稳健性结果

10次分层随机50/50划分中，逻辑回归测试准确率为：

`0.598 ± 0.050`，范围为`0.52—0.68`。

固定划分的准确率为0.64，位于重复实验范围内。固定划分结果可以保留用于与第二周对照，但不能单独代表模型的泛化性能。

## 4. 数据质量发现

自动端点检测对100条录音均返回非空候选段，但其中有9条候选语音段超过1秒。大部分正常候选段约为0.13—0.35秒。

因此：

- 自动返回非空候选不等于端点检测正确；
- 超过1秒的9条录音建议人工复听；
- 当前结果不能作为端点检测准确率的证明；
- 后续论文中应把这一点写入实验局限。

## 7. 复现方法

在`第三周`目录运行：

```powershell
C:\ProgramData\anaconda3\python.exe run_week3_experiments.py --full
```

全量运行约需3分钟，主要时间消耗在DTW训练集留一验证和测试集预测。

快速检查命令：

```powershell
C:\ProgramData\anaconda3\python.exe run_week3_experiments.py --smoke
```

注意：运行`--smoke`会用30条样本生成快速检查结果，不应将其CSV当作正式实验结果。正式交付前必须重新运行`--full`。
