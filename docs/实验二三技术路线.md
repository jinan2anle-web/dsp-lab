# 实验二 / 三 技术路线与模块边界

目的：先定边界再写代码。第二周的教训是三个人各自用 AI 独立完成，接口对不上（端点区间差 25 ms、`wav_parse` 的修复没回同步、复现清单指向别人机器）。这次把接口写死。

## 一、模块表（全部落在 `dsp/`）

| 模块 | 职责 | 输入 → 输出 | 用在 |
| --- | --- | --- | --- |
| `io_wav.py` | 纯 Python 解析 RIFF 头并读采样，不依赖 scipy | path → `(x: float64[-1,1], fs: int)` | 一 二 三 |
| `endpoint.py` | 去直流 + 双门限端点检测，返回样本区间 | `x, fs` → `(s0, s1)` 或 `None` | 一 二 三 |
| `framing.py` | 分帧 + 预加重 + 窗（矩形/汉明/海宁可切） | `x` → `[T, N]` | 二 |
| `fft_radix2.py` | **自写** radix-2 FFT + 位倒序 + 补零到 2^L | 实数 `[T,N]` → 复数 `[T,N]` | 二（得分点） |
| `mfcc.py` | 谱能量 → Mel 三角滤波 → 取对数 → DCT | `[T,N]` → `[T,13]` | 二 |
| `dtw.py` | 三前驱递推 + 欧氏距离（含 1/K 归一化） | `(T1,D), (T2,D)` → 距离、路径 | 三 |
| `app.py` | 界面：录音/选文件 → 识别 → 显示结果 | — | 三 |

## 二、接口冻结（先冻结，后实现）

```python
endpoint.detect(x, fs, *, frame_ms=25, hop_ms=10, min_len_ms=100) -> tuple[int,int] | None
    # 返回样本下标，半开区间 [s0, s1)

framing.frames(x, win_len=400, hop_len=160, window="hamming", preemph=0.97) -> np.ndarray  # [T, 400]

fft_radix2.fft(x, nfft=512) -> np.ndarray       # 复数 [T, 512]，实数输入走 rfft 也只留 257 列时另开函数

mfcc.extract(x, fs, n_mfcc=13, n_mels=24) -> np.ndarray   # [T, 13]

dtw.distance(a, b) -> float                     # a, b 均为 [T, D]
```

**端点口径只有一种：半开区间 `[s0, s1)`，单位是样本下标。** 禁止再出现两种写法——第二周一处是 `x[N1*hop : min(len(x),(N6+1)*hop+frame_len)]`，另一处是 `sig_raw[s0:s1]`，两者差一个 25 ms 帧长，直接导致两份结果对不上。

## 三、里程碑（每个里程碑一次 git 提交）

1. **端点定稿**：整段 / 端点段两种口径各跑一次 DTW，把 0.760 vs 0.540 的差异定位到具体样本，选定主线口径。
2. **FFT 对拍**：`dsp/fft_radix2.py` 与 `np.fft.rfft` 逐点比较，最大绝对误差 < 1e-10；附计算耗时对比表 → 实验二第一张图。
3. **MFCC 出图**：13 阶倒谱随时间的热图 + 与 16 维聚合特征的消融对比（这是「通过对比不同方法验证所选方法优势」的落点）。
4. **识别率表**：DTW + MFCC，按「整段/端点 × 三种窗 × 阶数 12/13/16」交叉，出混淆矩阵。
5. **界面 + 端到端**：`python -m dsp.app` 或 `scripts/exp3_recognize.py` 一条命令跑完全流程。
6. **报告**：实验二 + 实验三合并一份，学术论文格式。
