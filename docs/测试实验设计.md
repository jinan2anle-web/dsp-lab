# 测试实验设计（T1–T6）

> 目的：现在的结论只有一个数字——测试集 50 条里 40 条判对（0.800）。但这个数字是在**最理想条件**下测出来的：录音干净、同一支麦克风、同一个人、已经切好 1.5 s、模板刚好 5 条。
> 测试实验要回答的是：**这套系统在条件变差时还成不成立，从哪里开始崩。**
> 本文件是协议（设计），本周只跑 T1、T2，T3 顺手补，T4–T6 视时间。

## 1 被测系统与测量口径

| 项 | 定义 |
|---|---|
| 被测系统 | 模板库（每类 5 条训练录音的 MFCC）＋ DTW 最近模板判决 |
| 被测量（主） | 50 条测试集的识别率 = 判对条数 / 50 |
| 被测量（辅） | 混淆矩阵、每条判决耗时、最近/次近距离差 |
| 固定不变（控制项） | 划分（训练 01–05 / 测试 06–10，共 50 条）、MFCC 参数（24 Mel / 13 维 / 400 点帧 / 160 点移 / 汉明窗 / 预加重 0.97）、DTW 口径（三条前驱、K=13、越界 +inf）、模板数（除 T3 外恒 5） |
| 判定粒度 | **1 条 = 2 个百分点**。凡是差值 ≤ 1 条（2 个百分点）的，一律写「无差别」，不写「提高/下降」 |

## 2 三条设计原则

1. **单变量**：一次只动一个量，其余全部锁死；动两个量的实验必须拆成两张表。
2. **可复现**：每个实验一条命令、一个随机种子、一个 csv；种子写进 csv。
3. **先写预期，再看结果**：每个实验先写「我认为会怎样、为什么」，跑完对照；**不符合预期的结果比符合的更有价值**，必须在报告里解释，不许悄悄删。

## 3 六个实验

| 编号 | 变量 | 取值 | 控制项 | 预期（先写死） | 产出 |
|---|---|---|---|---|---|
| **T1 噪声** | 加性白噪声 SNR | ∞(无噪) / 20 / 10 / 5 / 0 dB | 其余同主结果 | 20 dB 基本不掉；10 dB 掉 1–3 条；5 dB 明显掉；0 dB 接近随机（0.10 左右） | `exp5_robustness.csv` 噪声行 + 折线图 |

### T1 协议细节

- 噪声功率按**语音段功率**定，不按整条功率：先用端点检测取 `[s0, s1)`，算语音段均方值 `P_s`，噪声方差 `σ² = P_s / 10^(SNR/10)`；整条加噪（含静音段也算加噪，更接近真实）。
- 种子：`seed = 0, 1, 2`（3 次），报告写「3 次平均 ± 极差」，csv 里三次都留行。
- 边界：0 dB 时若识别率仍 > 0.30，说明特征对噪声异常鲁棒，需检查是不是噪声没加进去（自测：加噪前后 `np.abs(x).mean()` 应显著变化）。
- 算力：50 条 × 5 档 × 3 种子 = 750 次判决，单次约 0.57 s（含特征）→ 约 7 分钟，可接受。

### T2 协议细节

- `apply_gain(x, factor)` 对整条乘 `factor`（含静音段与端点检测内部，保证条件一致）。
- 两套归一化各跑一遍，共 3 档 × 2 套 = 6 行。
- **推导**（写在报告里，作为「为什么这么设计」）：整体乘常数 c → 功率谱 × c² → log 后加 `2·ln c` 常量 → DCT 只把这个常量送到 c0，其余 12 维不变 → 所以 `none` 下只有 c0 变、距离变大；`cmn` 把每条序列的逐维均值减掉，c0 的平移被消掉 → 识别率应基本不变。
- 如果实测 `none` 也不掉，结论是「DTW 的距离归一化把这个平移吸收了」——这同样是有价值的结论，报告要写清是哪一种。

### T3 协议细节

- 每类取前 n 条模板（n = 1…5，模板即训练集 01–05 的前 n 条，顺序固定、不随机挑）。
- 报告同时给「绝对条数 / 50」与「相对 5 条模板的损失」。

## 4 记录格式（四张表统一）

`report/tables/exp5_robustness.csv` 列：

```
实验,条件,参数,重复次数,识别率,正确条数,总条数,耗时s,seed,备注
```

- `实验` ∈ {T1_noise, T2_gain, T5_speed}
- `条件` 是给人看的中文标签（如「SNR 10 dB」「gain ×2.0」「cmn」「none」）
- `参数` 是机器可读的数值（如 `10`、`2.0`）
- 距离/耗时等辅助量放 `备注` 或另开列，不许只留在控制台输出里。

## 5 失败判据与预案（提前写死，避免事后找理由）

| 现象 | 判定 | 处理 |
|---|---|---|
| T1 在 20 dB 掉超过 5 条 | 特征对噪声异常敏感 | 报告写明，并把「加噪训练」列为下周改进方向；不许改主结果口径 |
| T1 在 0 dB 仍 > 0.30 | 疑似噪声未真正加入 | 先查 `add_white_noise` 自测（SNR 实测偏差 < 0.5 dB），再复跑 |
| T2 两套归一化都不掉 | c0 影响被 DTW 吸收 | 报告改写结论：「整体增益对判决无影响」，并撤回「c0 携带响度信息就有害」的说法 |
| T3 曲线非单调 | 模板质量差异 > 数量收益 | 报告如实写，并给出「模板筛选」建议 |
| 任一实验耗时 > 10 分钟 | 跑批成本过高 | 降到 50 条单种子，报告注明 |
