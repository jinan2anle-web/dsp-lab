## 4 接口冻结（周一晚 22:00 前发出，之后改签名 = 返工）

```python
# dsp/mfcc.py —— 只允许加可选参数，签名与默认值不变
extract(x, fs=16000.0, *, n_mfcc=13, n_mels=24, nfft=512, win_len=400, hop_len=160,
        window="hamming", preemph=0.97, f_low=0.0, f_high=None,
        normalize="none", form="mfcc", use_delta=False)   # 新增 form / use_delta

# dsp/augment.py —— 新增模块，签名如下（只 A 可改实现，C 定签名）
add_white_noise(x, snr_db, *, fs=16000, seed=0)  -> np.ndarray   # 按语音段功率定噪声功率
apply_gain(x, factor)                            -> np.ndarray   # 整体乘常数（含静音段）
```

- `form="mfcc"` 返回 `[T, 13]`；`form="logmel"` 返回 `[T, 24]`（已取对数，未做 DCT）。
- `use_delta=True` 时，`form="mfcc"` 返回 `[T, 39]`（13 静态 + 13 Δ + 13 ΔΔ），**顺序固定：静态在前、Δ 居中、ΔΔ 在后**。
- 端点口径不变：半开区间 `[s0, s1)`、单位样本下标。
