## 3 冻结的接口（只 C 能改）

- `dsp.mfcc.extract(x, fs, *, n_mfcc=13, n_mels=24, nfft=512, ..., normalize="none")`：**只允许加可选参数，不允许改签名或默认值**
- `dsp.mfcc.mel_filterbank(n_mels=24, nfft=512, fs=16000.0, ...) -> [M, 257]`
- `dsp.dtw.distance(a, b) -> float`（三条前驱、`D(1,1)=d(1,1)`、越界 `+inf`、`K=13`）
- `dsp.templates.build(part="train", *, normalize="none", **mfcc_kwargs)` / `load()`
- 端点口径：**只有半开区间 `[s0, s1)`，单位样本下标**
- 谁改签名 = 返工；需要加参数先群里说，由 C 当天改完并通知全员。
