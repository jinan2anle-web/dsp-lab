# 零基础解释附件：这套系统在干什么

> 读者设定：完全没参与过实验一、二、三，也不知道 MFCC、DTW 是什么，但只要会基本 Python 就能跟上。
> 读法：先看第 1 节（一句话），再看第 7 节（名词表），中间任意顺序。

## 1 一句话版本

**人说话，把声音切成每 10 毫秒一小段，每段算 13 个数字（这就是"特征"），然后把待识别的整段"数字序列"和每个数字事先存好的模板序列比一遍，最像的那个就是识别结果。**
这套流程叫"模板匹配"，比的是**形状像不像**，而不是数值大小。

## 2 为什么不能直接比较波形

同一句话说两遍，录音不可能逐点相同：说话快慢差几十毫秒、起始位置差几百毫秒，波形就完全对不上。
所以要做三件事：

1. **切小段**（分帧）：每 25 ms 一帧、每 10 ms 挪一次，1.5 s 的录音得 148 帧（`(24000 − 400) / 160 + 1 = 148`）。
2. **每帧压成 13 个数字**（MFCC）：把这一小段声音的"音色指纹"提到 13 维。
3. **允许时间上的伸缩**（DTW）：两段序列长度一样也能比，长度不一样也能比——它会把一条时间轴"拉长/压扁"去对齐另一条。

## 3 为什么看频域

- 时域波形只告诉你"此刻空气压强多大"，同一句话大声说和小声说，波形幅度差一倍，形状一样。
- 频域告诉你"这一刻有哪些频率成分、各多强"——这是音色，也就是区分 a 和 i 的真正信息。
- 所以本实验的路线是：**时域 → 频域（频谱）→ 压缩（MFCC 13 维）→ 时间对齐（DTW）→ 判决**。

## 4 MFCC 七步（每一步在代码里的位置）

| 步 | 做什么 | 为什么 | 代码 |
|---|---|---|---|
| 1 预加重 | `x[n] − 0.97·x[n−1]` | 语音频谱高频弱，这一步把高频抬起来，让各频段"公平" | `dsp/framing.py: preemph` |
| 2 分帧 | 400 点一帧、160 点一移 | 声音在 25 ms 内可近似不变 | `dsp/framing.py: frames` |
| 3 加窗 | 乘汉明窗 | 防止帧两端被"硬切"产生假高频 | `dsp/framing.py: window` |
| 4 FFT | 512 点（400 补零到 512） | 从时域变到频域 | `dsp/fft_radix2.py: fft`（自己写的，不是 `np.fft`） |
| 5 功率谱 | `|X[k]|²` | 能量大小比相位重要 | `dsp/mfcc.py: spectrum_energy` |
| 6 Mel 滤波 + 取对数 | 24 个三角滤波器加权后 `ln` | 人耳对低频敏感、高频迟钝（Mel 刻度）；取对数把"响度"变成加法 | `dsp/mfcc.py: mel_filterbank`（加权）/ `mel_spectrum`（只做加权矩阵乘，不含 ln）/ `from_frames`（`np.log(s + EPS)`，EPS=1e-10） |
| 7 DCT | 离散余弦变换取前 13 个系数 | 24 个数之间高度相关，DCT 去相关，压到 13 维 | `dsp/mfcc.py: dct_matrix / from_frames` |

结果：一条 1.5 s 录音 → 一个 **148 行 × 13 列** 的矩阵（`[T, 13]`，T=148）。第 0 列（c0）是"这一帧有多响"，其余 12 列是音色细节。

## 5 DTW 三句话

1. 两个序列分别有 N 帧、M 帧，DTW 建一张 N×M 的表，`D(i,j)` = 把前 i 帧和前 j 帧对齐的最小累计代价。
2. 每一格只能从**三个方向**过来：正上方 `(i−1,j)`、斜上 `(i−1,j−1)`、正左 `(i,j−1)`；取三者最小，加上本格的距离。**没有第四个方向**（讲义明确只有三条前驱）。
3. 从 `(1,1)` 走到 `(N,M)`，终点那格的值就是两段序列的"距离"，越小越像。本实验的距离是 `d = (1/13)·√Σ(每维差的平方)`——**除以 13 是除以维数，不是帧数**，这一步最容易写错。

## 6 四个必须知道的口径

1. **0.800** = 50 条测试录音里判对 40 条。因为只有 50 条，**1 条就是 2 个百分点**，所以 0.780 与 0.800 之间不叫"提高"。
2. **混淆矩阵**：10 类 × 10 类的表，行是真实类别，列是判成什么。对角线是判对数。本实验 10 个类里 5 个全对（0/3/5/7/9），类 6 与类 8 只有 0.40——**错例集中在语音上相近的字**，不是随机错。
3. **0.760 与 0.800 不能直接比**：0.760 是实验一用"时域特征 + 段内逐维归一化 + 带宽 0.35 的 Sakoe–Chiba 约束带"得到的；本实验不做归一化、不加约束带。**如果去掉段内归一化，实验一只有 0.400**——所以两者是不同条件下的两个数，只能说"频域特征不需要靠归一化补救"，不能说"高了 2 条"。
4. **端点检测是可选件**：主结果用整段 1.5 s，端点检测只作为对照（总数一样 40/50，但耗时从 28.4 s 降到 7.5 s）。

## 7 名词表

| 名词 | 一句话解释 |
|---|---|
| 采样率 16 kHz | 每秒记 16000 个点；1.5 s = 24000 点 |
| 帧 / 帧移 | 一帧 400 点（25 ms）；帧移 160 点（10 ms），相邻帧有重叠 |
| 汉明窗 | 一种两端平滑到 0 的权重曲线，减少切帧造成的假高频 |
| 功率谱 | 每个频率成分的能量大小 |
| Mel 刻度 | 模拟人耳听觉的频率刻度：低频分得细、高频分得粗 |
| Mel 滤波器组 | 24 个三角形，第 m 个只在某一段频率上有非零权重 |
| DCT | 把 24 个相关的数换成 13 个互不相关的数 |
| c0 | 第 0 个倒谱系数，代表整帧总能量（"多响"） |
| CMN | 倒谱均值归一化：把每条序列每一维减去自己的均值，消掉整体偏移 |
| DTW | 动态时间规整：允许拉伸时间轴来对齐两条序列 |
| 累计代价矩阵 | DTW 的那张 N×M 表，`D(i,j)` 是从左上走到 (i,j) 的最小代价 |
| 模板 | 事先存好的一条参考序列（本实验每类 5 条） |
| 最近模板判决 | 待识别序列和所有模板算距离，取最小的那个模板的类别 |
| SNR | 信噪比，单位 dB；20 dB 表示信号功率是噪声的 100 倍 |
| 段内逐维归一化 | 每条序列每一维减均值除标准差（实验一的预处理，本实验不用） |
| 约束带 / Sakoe–Chiba | 限制 DTW 路径不能离对角线太远，省时间（本实验不用） |

## 8 本周三件事为什么重要

1. **语谱图（图 2.4/2.5）**：把 `[T,13]` 之前的中间结果画出来，让人**看见**"频域特征到底长什么样"，而不是只有一堆数字。答辩时这也是一张能讲两分钟的图。
2. **变体消融（P1）**：现在报告说"用 24 个 Mel、13 维"，但从没验证过换个数会怎样。消融就是"换一档参数，看识别率值不值这个代价"。
3. **测试实验（T1/T2）**：0.800 是在理想条件下测的。加噪、改音量之后还成不成立——这是老师这周新加的要求，也是从"做完实验"走向"验证结论"的分界线。
