## 3 接口契约（冻结，只能 C 改）

签名、返回形状、边界口径，三项都对上才算交付。

| 函数 | 签名 | 返回 | 硬口径 |
|---|---|---|---|
| `fft_radix2.fft` | `fft(x, n=None)` | `complex ndarray` | 基 2 DIT，自写位倒序 + 蝶形；`n` 必须是 2^L，不足补零；**不许 `np.fft`** |
| `framing.frames` | `frames(x, win_len=400, hop_len=160)` | `[T,400]` | 1.5 s 应得 148 帧；端点处理"左对齐、不足补零" |
| `framing.window` | `window(n, kind="hamming")` | `[n]` | 三种窗：`rect` / `hamming` / `hanning` |
| `mfcc.mel_filterbank` | `mel_filterbank(n_mels=24, nfft=512, fs=16000, f_low=0.0, f_high=8000.0)` | `[24,257]` | `Σ_m H_m(k) ≈ 1`；中心频率**是频点序号不是 Hz**；逆 Mel 用 **1125** |
| `mfcc.extract` | `extract(x, fs=16000, normalize="none"\|"cmn")` | `[T,13]` | **含 c0**，n=0..12；`normalize` 默认 `"none"`（消融另跑 `"cmn"`） |
| `dtw.distance` | `distance(a, b)` | `float` | `d=(1/K)·√Σ(x_i−y_i)²`，**K=13 是维数不是帧数**；三条前驱；`D(1,1)=d(1,1)` 后从 `(2,2)` 递推；越界取 `+inf`；返回 `D(N,M)` |
| `templates.build` | `build(split="01-05")` → 写 `out/templates/`<br>`load()` → `(names, arrays)` | 50 个 `.npy` + `index.csv` | 每类 5 条；识别取**最小距离** |

**六条谁都不能违反的算法口径**（写错任何一条，全部数字作废）：

1. FFT 自己写，特征路径里 grep 不到 `np.fft` / `scipy.fft`（自测块除外）。
2. MFCC 六步：预加重 `H(z)=1−0.97z⁻¹` → 分帧 400/160 + 汉明窗 → 512 点 FFT → `E=|X|²` → Mel 三角组 `S(i,m)=Σ_k E(i,k)H_m(k)` → `mfcc=√(2/M)·Σ ln S·cos[πn(2m−1)/(2M)]`。
3. `Mel(f)=2595·lg(1+f/700)`；`f(m)=(N/f_s)·F⁻¹_Mel(F_Mel(f_l)+m·(F_Mel(f_h)−F_Mel(f_l))/(M+1))`；`F⁻¹_Mel(b)=700(e^{b/1125}−1)`——**1125，不是 1127**。
4. DTW 只有三条前驱 `(i−1,j)`、`(i−1,j−1)`、`(i,j−1)`；越界 `+inf`，**不许用 0**。
5. `1/K` 的 K = MFCC 维数 13。
6. MFCC 13 维含 c0；不要出现 12 阶与 13 维混用的表。

## 8 引用实验一数字时的强制前提（写报告时照抄这段）

实验一的最好结果 **DTW 0.760**（整段、测试集 50 条）**必须带三个前提**，缺一个就是错：

1. **依赖段内逐维归一化**：去掉"每句特征序列段内零均值单位方差"这一步，同一个 DTW 只剩 **20/50 = 0.400**。所以不能写成"时域特征识别率 0.760"。
2. **不能说"16 维时域特征"**：那 16 维里 `dim0–dim5` 跨 100 条样本 `std = 0.000000`（对已归一化序列又求了一次均值/标准差），**实际只有 10 维可变**。正确说法是"有效维不足 + 训练样本仅 50 条"，不能归因"维数太高过拟合"。
3. **0.540 不能当"端点更差"的证据**：实验一端点段中位仅 0.195 s（真实语音中位 0.600 s，69/100 条不足一半，8/100 条反而拉长）。正确说法是"实验一的自动端点实现既严重截断又偶发过度延伸，本次改用整段输入"。

其余可引：逻辑回归 0.640、高斯 NB 0.540、KNN 0.520、随机森林 0.520、SVM 0.480、决策树 0.480；三窗五折 0.640 / 0.640 / 0.660；类 6 在 7 个分类器上召回全部 0.40。

> 注意两个 0.640 是两件不同的事（逻辑回归测试集 vs 矩形窗五折），表里必须标口径。
