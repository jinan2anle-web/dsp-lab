T1 加噪口径自测（exp5_robustness.py 的 _snr_selftest()）
=========================================================
目的：开跑 750 次判决前先核 SNR 口径，偏差超过 0.5 dB 就终止，避免白跑。
设定关系：σ² = P_s / 10^(SNR/10)，P_s 取语音段 [5600,23760) 的均方（= 端点检测区间）。

文件        : 0_01.wav
P_s(语音段) : 0.0059679856
语音段区间  : (5600, 23760)  —— 与 dsp/endpoint.detect() 返回值一致

  设定 SNR      实测 SNR      偏差       判定
  ------------------------------------------------
    20.0 dB     20.034 dB   0.0339 dB   OK
    10.0 dB     10.034 dB   0.0339 dB   OK
     0.0 dB      0.034 dB   0.0339 dB   OK

阈值：|实测 − 设定| < 0.5 dB —— 三档全部通过。
结论：add_white_noise 的噪声功率口径正确，可以开跑 T1 全量。
加噪前后自检：inf 档 add_white_noise(x, inf, seed=0) 与原信号逐位相同（np.array_equal=True）。

附：mfcc 新参数形状自测（extract 默认行为未变，基线仍 40/50=0.800）
  extract(x)                    -> [148, 13]   默认（主口径）
  extract(x, form="logmel")     -> [148, 24]   A 的 form 参数
  extract(x, use_delta=True)    -> [148, 39]   13 静态 + 13 Δ + 13 ΔΔ
